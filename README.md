Aplicació Android feta amb **Kotlin** i **Jetpack Compose** que calcula l'índex de massa corporal (IMC) a partir del pes i l'alçada.

## Funcionalitats

- Introduir el pes (kg) i l'alçada (cm).
- Calcular l'IMC amb un botó.
- Mostrar el resultat a la pantalla.

## Fórmula

IMC = pes (kg) / alçada (m)²

| IMC        | Categoria   |
|------------|-------------|
| < 18,5     | Baix pes    |
| 18,5 - 24,9| Pes normal  |
| 25 - 29,9  | Sobrepès    |
| ≥ 30       | Obesitat    |

## Tecnologies

- Kotlin
- Jetpack Compose
- Android Studio

## Com executar-la

1. Clona el repositori.
2. Obre'l amb Android Studio i sincronitza Gradle.
3. Prem **Run ▶** amb un emulador o dispositiu.
